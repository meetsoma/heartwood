# Example arc

## Why this arc exists

An arc is a themed body of work with a through-line — the sentence explaining why these cycles
belong together. An arc directory with members but no `cycle.md` is a folder pretending to be a
grouping.

## Through-line

Demonstrate the format against real tooling, so the spec has something falsifiable attached to it.
